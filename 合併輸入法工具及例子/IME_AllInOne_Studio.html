三合一 IME 碼表與雲端編譯生成器

支援同時載入並合併最多 3 個本機碼表檔案，完全離線一站式輸出 Windows (TSF DLL)、macOS (Universal .app / 原生 .cin) 與 Android / iOS (萊姆 / Rime)。

最多 3 個本機碼表合併＋獨立編碼設定 Windows + macOS + 手機三合一 支援香港 HKSCS 與 \U000XXXXX 漢字 100% 離線瀏覽器運算
