以上有合併不同輸入法的工具及兩個大型一個中型.cin檔案，可直接掛到支援的輸入法，已把常用字移前方便打字，並配大字庫。但粵拼與港式/教院式的J字定義分別較大，打Ji之類會出現大量不相關的字，實踐發覺不太實用，初學使用HK_and_IEd_Cantonese(港式容錯合併教院式)應該比較方便。

# IME 碼表與雲端編譯生成器　IME_AllInOne_Studio.html

本工具是一套 100% 離線執行的瀏覽器單頁應用（`IME_AllInOne_Studio_v6.5.html`），無需安裝開發環境或上傳任何個人碼表，即可將純文字碼表一鍵轉換並打包為 **Windows（TSF `.dll`）**、**macOS（Universal `.app` / 原生 `.cin`）** 與 **Android / iOS（Rime / 萊姆）** 全平台可用的自訂輸入法。

## 核心功能與特色

* **多檔合併與智能辨識**：支援同時載入最多 **3 個本機碼表檔**（`.txt` / `.tt` / `.cin` / `.yaml` / `.csv`），自動偵測 UTF-8、UTF-16、Big5 與 GBK 編碼，並依字元特徵自動判斷「編碼在前」或「字詞在前」，支援引號包裹與多欄詞組處理。


* **去重與碼表體檢**：內建 Unicode NFC 正規化、零寬字元清理及跨檔／單檔去重功能（保留首次出現順序），即時顯示最長編碼、最高重碼字數及亂碼預警。


* **客製化外觀與港式操作**：支援多中文語系掛載（`zh-HK` / `zh-TW` / `zh-MO` / `zh-CN` / `zh-SG`）、文字生圖自訂工作列圖示（自動生成 32-bit `.ico` 與 `.png`）、10 字選字框加高不加寬，以及　可選 **空白鍵（`Space`）向下翻頁並於末頁循環回到第 1 頁**（數字鍵 `1–9` 及 `0` 選字）。



## 快速使用步驟

1. **匯入碼表**：拖放 1 至 3 個碼表檔至步驟 1 區塊，確認預覽與體檢摘要無誤。


2. **設定參數**：輸入顯示名稱與英文代號，按需調整語系、文字圖示、選字框高度及空白鍵翻頁模式。


3. **打包編譯與安裝**：下載「三合一全平台包 (`.zip`)」並上傳至 GitHub 倉庫，於 **Actions** 分頁執行對應 Workflow 即可取得成品（Windows 以管理員執行 `install_ime.bat`；macOS 執行 `install_macos_ime.command` 後重新登入）。
